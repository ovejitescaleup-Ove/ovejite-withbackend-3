# Ovejite — Retro Digital Marketing Portfolio

A completely new Next.js portfolio direction, rebuilt from scratch rather than re-skinning the previous site.

## Visual direction
- Retro-futurist / digital performance console aesthetic
- Dark ink, electric blue, acid-lime and cyan
- Editorial typography with Space Grotesk + DM Mono
- Dashboard/terminal visual language
- Strong case-study storytelling
- Responsive mobile layout with no floating metric cards covering the portrait
- No Base44 dependency
- No Supabase dependency for the public portfolio
- No Recharts dependency
- Simple Next.js App Router project

## Run
```bash
npm install
npm run dev
```

## Production
```bash
npm run build
npm start
```

## Deploy to Vercel
Import the GitHub repository as a Next.js project. No special build command is required; `npm run build` is already configured.

## Portrait
The current About section intentionally uses a clean OV monogram placeholder so the old screenshot's ROAS/Conversions/Monthly Spend cards are not carried into the new design. Replace the placeholder with the original high-resolution portrait when available.
